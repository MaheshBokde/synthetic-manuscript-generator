# synthetic-manuscript-generator

This project generates realistic Indic manuscript folios in three scripts:
- Devanagari
- Modi
- Sharada

## 📌 Overview
The generator creates synthetic manuscript images with:
- Realistic backgrounds (palm-leaf, aged paper, parchment)
- Ink variations and artifacts (smudges, blur, faded strokes)
- Paired `.md` annotation files for OCR training
